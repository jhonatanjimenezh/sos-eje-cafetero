# Contribuir

Este proyecto prioriza cambios pequeños, verificables y seguros para operación de emergencia.

1. No incluya datos reales de víctimas en issues, fixtures o pruebas.
2. Abra un issue para cambios funcionales grandes.
3. Mantenga la separación entre endpoints públicos y operacionales.
4. Todo cambio relacionado con despacho, matching o IA debe mantener revisión humana.
5. Incluya pruebas para reglas de priorización, privacidad y geolocalización cuando se amplíen estos módulos.
