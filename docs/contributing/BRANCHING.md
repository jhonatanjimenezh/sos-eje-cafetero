# Branching

- `main`: siempre revisable/operable.
- `feat/<issue>-<slug>`: nueva capacidad.
- `fix/<issue>-<slug>`: corrección.
- `docs/<issue>-<slug>`: documentación.

No trabajar directamente sobre `main` salvo documentación operativa urgente y de bajo riesgo. Cambios funcionales deben ir por PR.
