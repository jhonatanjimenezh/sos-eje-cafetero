# Mensaje corto para compartir con voluntarios

Gracias por ofrecerte a ayudar. El proyecto está preparado para contribución paralela.

1. Entra al repositorio.
2. Lee `docs/architecture/CONTRIBUTOR_START_HERE.md`.
3. Elige un workstream en `docs/contributing/WORKSTREAMS.md`.
4. Comenta `TOMO ESTE WORKSTREAM` en el issue correspondiente.
5. Si usarás IA, sigue `docs/contributing/AI_HANDOFF.md` para cargar el contexto mínimo.
6. Abre un PR pequeño y evita datos personales reales.

Prioridad: PWA offline, sincronización segura, infraestructura, resiliencia y capas geoespaciales.
