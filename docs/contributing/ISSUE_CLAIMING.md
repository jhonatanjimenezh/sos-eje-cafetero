# Claiming an issue

Para evitar trabajo duplicado durante la emergencia:

- comenta `TOMO ESTE WORKSTREAM` antes de comenzar;
- indica qué parte exacta tomarás si el issue es grande;
- si no hay actividad durante varias horas y otro voluntario necesita avanzar, coordinen en el mismo issue;
- enlaza tu rama/PR tan pronto exista;
- si abandonas el trabajo, comenta `LIBERO ESTE WORKSTREAM` y deja un handoff breve.

No reserve tareas que no pueda empezar razonablemente pronto.
