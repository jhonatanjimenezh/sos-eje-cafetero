# Contributor Start Here

Si acabas de llegar al proyecto:

1. Lee `README.md` del repositorio.
2. Lee `docs/architecture/README.md`.
3. Lee `docs/architecture/SYSTEM_OVERVIEW.md`.
4. Abre `docs/contributing/WORKSTREAMS.md`.
5. Elige un issue y comenta `TOMO ESTE WORKSTREAM`.
6. Si vas a usar IA, carga `docs/contributing/AI_HANDOFF.md` en tu sesión.
7. Trabaja solo el alcance del issue y abre PR pequeño.

## Prioridad actual

P0: resiliencia, PWA offline, sincronización segura, infraestructura, identidad y pruebas de carga.

## No bloquees una emergencia

El flujo SOS público debe seguir funcionando incluso si autenticación, WhatsApp, IA o biometría están degradados.
