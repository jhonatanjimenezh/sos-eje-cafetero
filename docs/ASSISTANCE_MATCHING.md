# Matching entre necesidades y ayuda disponible

Un damnificado puede declarar necesidades cuando su expediente ya fue enviado a revisión. El motor solo propone matches automáticos para perfiles `VERIFIED`.

Las ofertas contienen categoría, cantidad, unidad, GPS y radio máximo. El algoritmo inicial prioriza misma categoría, radio compatible, cantidad y menor distancia.

El resultado queda `PROPOSED`. Un funcionario autorizado lo cambia a `APPROVED`; recién entonces se revelan los datos mínimos necesarios para coordinar entrega.

No publicar teléfonos ni domicilios exactos de damnificados o donantes en el mapa público.
